Move one level upward to the parent folder: $ cd ..

Add GitHub user to terminal: $ git config --global users.email "danielleliew0325@gmail.com"
                             $ git config --global users.name "L1B15"

Add changes of a commit to the staging area: $ git add .
Then commit the changes: $ git commit -m "Did this today."
Then push to remote repos: $ git push

从远程下载（不改本地代码）:  $ git fetch

从远程fetch并且merge: $ git pull

给本地的Git仓库绑定一个远程仓库，并且命名为origin:  $ git remote add origin https://github...

强行用本地main branch覆盖远程，并且建立跟踪关系:  $ git push -u origin main --force
(--u 建立默认关系）

把branch传到GitHub，远程创建一个同名branch，建立tracking:  $ git push -u origin branch-name
(以后可以直接push和pull了)
